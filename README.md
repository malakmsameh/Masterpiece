# 🥘 Sahtein

**Live Demo:** [INSERT_LIVE_URL_HERE](https://malakmsameh.github.io/Masterpiece/)

Sahtein is a modern, responsive web application designed for food lovers. It combines Middle Eastern culinary traditions with modern health tracking, allowing users to discover recipes, plan meals, and monitor their daily wellness.

## ✨ Features

- **Recipe Discovery:** Browse and search through a curated list of recipes with full nutritional breakdowns.
- **Healthy Day Tracker:** Log daily meals, track macronutrients, and monitor water intake.
- **Intermittent Fasting:** A built-in timer with customizable fasting plans (12:12, 16:8, etc.) and weekly history.
- **Meal Planner:** Plan your week and automatically generate a shopping list.
- **AI Recipe Assistant:** Input ingredients you have at home to find matching recipes.
- **Community:** A space for users to share kitchen stories, ask questions, and interact.
- **Admin Dashboard:** A full CRUD (Create, Read, Update, Delete) workspace to manage recipes, ingredients, categories, users, and AI-generated content.
- **Authentication:** Simple demo login/signup with persistent user profiles (including avatar uploads).

## 🛠️ Tech Stack

This project is built using clean, vanilla web technologies:
- **HTML5** (Semantic structure)
- **CSS3** (Custom properties, Flexbox, CSS Grid, Responsive design)
- **Vanilla JavaScript** (ES6+, DOM manipulation, `localStorage` for data persistence)
- **Font Awesome** (Icons)
- **Google Fonts** (Playfair Display & DM Sans)
